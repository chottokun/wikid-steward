# スラッグ生成・規格化命名規則

原本ファイルの相対パスから、グローバルに一意かつ安全な Slug 名を決定論的に生成する。

## 生成アルゴリズム要件

1. **Unicode NFC 正規化**: macOS 特有の NFD 濁点分解問題および Git 重複検知コンフリクトを 100% 防止。
2. **パス区切り置換**: `/` および `\` を一律アンダースコア `_` に変換。
3. **小文字化 & 文字置換**: ASCII 文字を小文字化。OS 禁止文字、スペース、記号をハイフン `-` に置換（日本語等のマルチバイト文字 `\w` は保護・維持）。
4. **重複セパレータ整理**: `[-_]{2,}` を単一セパレータに縮約し、端部の不要な記号をトリミング。
5. **100バイト安全切り詰め (Truncate)**: Multi-byte 文字の途中で壊れないよう UTF-8 エンコード長を1文字ずつ累積計算し、累積 100 バイトを超えない範囲でトリミング。
6. **衝突解決規則**: 生成結果が同一でパース結果ハッシュが同一の場合は処理スキップ。パース内容が異なる場合は `-1`, `-2` サフィックスを付与。
